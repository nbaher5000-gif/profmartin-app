# ماژول اسکن سه‌بعدی پا (LiDAR)

ماژول نیتیو محلی Expo که با ARKit و سنسور LiDAR، پا را اسکن و اندازه‌گیری می‌کند.
فقط روی iOS و روی دستگاه‌های دارای LiDAR کار می‌کند (iPhone 12 Pro به بالا، از جمله **iPhone 15 Pro Max**).

## چه چیزی را اندازه می‌گیرد

| خروجی | توضیح |
| --- | --- |
| `lengthMm` | طول پا از پاشنه تا بلندترین انگشت |
| `ballWidthMm` | عرض پنجه (محل عریض‌ترین بخش کف پا) |
| `maxWidthMm` | عریض‌ترین مقطع در کل طول پا |
| `heelWidthMm` | عرض پاشنه |
| `instepHeightMm` | ارتفاع روی پا |
| `ballGirthMm` | دور پنجه (تخمینی، با مدل نیم‌بیضی) |
| `confidence` | کیفیت اسکن بین ۰ و ۱ |
| `pointCloudPath` | فایل PLY ابر نقاط در پوشه‌ی Documents اپ |

## روش کار

1. نشست `ARWorldTrackingConfiguration` با `planeDetection: .horizontal` و `frameSemantics: .smoothedSceneDepth` بالا می‌آید.
2. وقتی کف اتاق پیدا شد، با `start()` یک پرتو از مرکز صفحه به کف فرستاده می‌شود تا ارتفاع دقیق کف و مرکز ناحیه‌ی اسکن ثبت شود.
3. در هر سه فریم، پیکسل‌های نقشه‌ی عمق به مختصات جهانی تبدیل می‌شوند. فقط نقاطی می‌مانند که:
   اطمینان LiDAR بالا باشد، بین ۰٫۵ تا ۲۲ سانتی‌متر بالای کف باشند و داخل شعاع ۲۶ سانتی‌متری ناحیه بیفتند.
4. نقاط در گرید ووکسل ۲ میلی‌متری انباشته می‌شوند تا تکرار حذف شود.
5. با `finish()` روی ابر نقاط PCA دوبعدی اجرا می‌شود؛ محور بلند = طول پا، محور عمود = عرض.
   جهت پاشنه/پنجه از مقایسه‌ی ارتفاع دو سر پا تشخیص داده می‌شود.

## استفاده در جاوااسکریپت

```js
import { NativeFootScanView, isFootScanSupported, requestScanPermission } from "../../modules/foot-scan";
```

روی وب، اندروید و Expo Go ماژول وجود ندارد: `isFootScanSupported()` مقدار `false` برمی‌گرداند
و صفحه‌ی `src/footScan/FootScanScreen.js` حالت جایگزین را نشان می‌دهد.

## ساخت بیلد قابل نصب (این ماژول در Expo Go اجرا نمی‌شود)

کد نیتیو دارد، پس باید یک **development build** ساخته شود:

```bash
npm install --global eas-cli
```

```bash
eas login
```

```bash
eas build --platform ios --profile development
```

پیش‌نیازها:

- اشتراک **Apple Developer Program** (سالانه ۹۹ دلار). بدون آن نمی‌توان بیلد را روی آیفون نصب کرد.
- شناسه‌ی دستگاه (UDID) آیفون باید در حساب Apple ثبت شود؛ `eas device:create` این کار را راه می‌اندازد.
- بیلد روی سرورهای ابری EAS انجام می‌شود، پس به مک نیاز نیست.

بعد از نصب بیلد، سرور توسعه با `npx expo start --dev-client` بالا می‌آید و تغییرات جاوااسکریپت
بدون بیلد مجدد اعمال می‌شود. بیلد دوباره فقط وقتی لازم است که کد Swift تغییر کند.
